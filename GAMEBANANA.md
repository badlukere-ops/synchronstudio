## Body (English) — copy & paste

```
Synchronstudio is a free, private browser dubbing game for friends.

Create a room, share the 5-digit code (or invite link) only with people you trust, pick a scene, assign roles, record your lines in sync with the video, then watch the premiere together — with outtakes, ratings, and download.

Site defaults to English. Switch EN | DE anytime in the header.

▶ PLAY (no download):
https://synchron-studio.github.io/synchronstudio/

How to play
1. Open the link above
2. Allow your microphone
3. Host: Create room → send the 5-digit code / invite link to friends
4. Friends: Join with the code
5. Pick a scene → record → premiere → laugh
6. Optional: save the video / outtakes reel

Features
• Dozens of ready scenes (anime, movies, memes)
• Voice effects (phone, radio, monster, helium, …)
• Blind mode, match mode, battle royale, duel
• Cinema premiere + outtakes
• Save finished dub as video

Requirements
• Modern browser (Chrome / Edge recommended)
• Microphone + headphones
• Friends in the same private room (P2P — no public lobby browser)

Notes
• Fan project for fun with friends — we do not monetize this
• Scene clips belong to their respective rights holders; we remove scenes on request
• Connection issues: try phone hotspot, disable VPN, hard-refresh (Ctrl+F5)

No Steam/Epic install. Just the link.
```
